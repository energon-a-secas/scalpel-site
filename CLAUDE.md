# CLAUDE.md: Scalpel

Dissect a Claude skill from a zip or pasted SKILL.md: router quality, body structure, scripts and references, and the caveats to fix before it ships.

**Live:** scalpel.neorgon.com · **Port:** 8870

## Run

```bash
make serve
```

Then open http://localhost:8870. It must be served over HTTP: the app is ES modules, and `file://` blocks them.

## Data

- `localStorage['scalpel-v1']`

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.
